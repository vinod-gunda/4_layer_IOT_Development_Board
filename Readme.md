# 4-Layer ESP32-C3 Development Board

A custom **4-layer ESP32-C3 development board** designed from scratch using **KiCad 10** as part of my embedded systems and PCB design learning.

## Key Features

- ESP32-C3 based controller
- USB-C, USB-UART, Li-Po charging and power management
- SD Card, Flash Memory and sensor interfaces
- 4-layer PCB with power and GND distribution

## PCB Design Skills

- Custom schematic symbol design
- Custom footprint design
- Custom logo-to-footprint conversion
- Hierarchical schematic design
- PCB layout, routing and DRC verification

## Tools & Technology

- **KiCad 10**
- **ESP32-C3**
- **4-Layer PCB**

## Repository Contents

- KiCad schematic files
- PCB layout files
- Custom symbols and footprints
- Project images

## Purpose

This project was developed for **learning, prototyping, and improving practical PCB design skills**.
